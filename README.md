# LOUPEUR

Browser-based basic DAW for my personal use.

- create loops
- add layers
- sequence layers
- `.wav` export
- `.loupeur` files for project backup
- microphone lag compensator
- usable by absolute beginners

![LOUPEUR](image.png)

## Run it

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
